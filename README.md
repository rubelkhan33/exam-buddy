# JobPrep AI — চাকরির প্রস্তুতির অ্যাপ

| Folder | কী আছে |
|---|---|
| `jobprep-app/` | অ্যাপ (Next.js 16 + PWA)। ৭টি স্ক্রিন: হোম, টপিক, সেটআপ, পরীক্ষা, ফলাফল, রিভিউ, অ্যানালিটিক্স + PDF |
| `JobPrep-AI-Data/` | বইয়ের PDF → Gemini OCR → প্রশ্নের JSON. বিস্তারিত: `JobPrep-AI-Data/README.md` |

## অ্যাপ চালানো

```
cd jobprep-app
npm install          # প্রথমবার
npm run dev          # তারপর browser এ http://localhost:3000
```

মোবাইলে দেখতে: একই Wi-Fi তে ফোন থেকে `http://<কম্পিউটারের-IP>:3000` খুলুন।
Production: `npm run build` তারপর `npm start`। Test: `npm test`।

## পরীক্ষার নিয়ম (কোডে যেভাবে আছে — `jobprep-app/src/lib/exam.ts`)

- শুধু বাছাই করা টপিক থেকে প্রশ্ন; এক বা একাধিক টপিক, বা “সব সিলেবাস”।
- ১০০ প্রশ্ন = ৭০ নতুন + ২৫ আগের ভুল + ৫ রিপিট। কোনো ভাগে প্রশ্ন কম থাকলে বাকি ভাগ থেকে পূরণ হয়; টপিকে ১০০টির কম প্রশ্ন থাকলে যত আছে তত।
- নতুন প্রশ্নের ক্রম: বিসিএস-এ বারবার আসা (বেশি বার আগে) → বিসিএস একবার → পিএসসি → ব্যাংক → অন্যান্য।
- “আগের ভুল” = শেষবার ভুল বা উত্তর না দেওয়া প্রশ্ন, সবচেয়ে বেশি বার ভুল হওয়াগুলো আগে।
- সময়: প্রতি ১০০ প্রশ্নে ৬০ মিনিট (প্রতি প্রশ্নে ৩৬ সেকেন্ড)। সময় শেষ হলে নিজে থেকে জমা হয়।
- টাইমার চালু করলে নেগেটিভ মার্ক বাধ্যতামূলক; টাইমার ছাড়া চাইলে বন্ধ রাখা যায়।
- নেগেটিভ: বিসিএস বা ব্যাংক ট্যাগ থাকলে −০.৫০, বাকি সব −০.২৫।
- একবার অপশন বাছলে বদলানো যায় না।
- ডেটা আপাতত ফোন/ব্রাউজারেই (localStorage) থাকে, লগইন নেই।

## Vercel এ deploy

1. https://vercel.com → **Add New… → Project** → GitHub repo `exam-buddy` বাছুন (Import)।
2. **Root Directory** → `Edit` → `jobprep-app` বাছুন। (জরুরি — অ্যাপটি এই ফোল্ডারে আছে)
3. Framework: Next.js (নিজে থেকে ধরবে)। বাকি সব যেমন আছে রেখে **Deploy**।
4. কোনো Environment Variable লাগবে না — Gemini key শুধু ডেটা তৈরির স্ক্রিপ্টে লাগে, অ্যাপে নয়।

নতুন বই যোগ বা ডেটা বদলালে `git push` করলেই Vercel নিজে থেকে আবার deploy করবে।
